# Do not license third-party materials by default

The September Example Project will not add a blanket open-source license because the repository combines original teaching work with Pokémon challenge data and reference materials whose relicensing rights have not been established. The README and release will state that third-party materials are not relicensed and that any later code-license decision requires real Challenge Advisor or rights-holder confirmation; this avoids making an effectively irreversible permission grant as a placeholder.
