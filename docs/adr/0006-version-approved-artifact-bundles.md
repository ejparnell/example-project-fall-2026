# Version approved Artifact Bundles

Each approved Artifact Bundle will be committed as a small, complete, versioned directory under `artifacts/` and attached as an identical archive to its Milestone Release. Every bundle begins with a `README.md` that reports the work completed, findings, how noteworthy conditions were handled, limitations, verification steps, and a guide to its detailed evidence; EDA findings are summarized there instead of being stranded in notebook output. Bundle Integrity validates the README against its declared, versioned report schema and the bundle evidence; later editorial contracts add a new schema and renderer rather than changing the retained v1 renderer. Routine, exploratory, failed, and bulky simulator outputs remain ignored; the approved September bundle retains that overview, its manifest, configuration, run receipt, machine-readable match evidence, summary, integrity result, one representative replay, interpretation, and limitations so reviewers can inspect it in Git while releases provide a durable distribution point.
