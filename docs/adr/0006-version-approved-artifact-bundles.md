# Version approved Artifact Bundles

Each approved Artifact Bundle will be committed as a small, complete, versioned directory under `artifacts/` and attached as an identical archive to its Milestone Release. Routine, exploratory, failed, and bulky simulator outputs remain ignored; the approved September bundle retains its manifest, configuration, run receipt, machine-readable match evidence, summary, integrity result, one representative replay, interpretation, and limitations so reviewers can inspect it in Git while releases provide a durable distribution point.
